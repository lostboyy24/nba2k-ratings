# NBA 2K27 Player Ratings (unofficial fan site)

Static site (HTML/CSS/vanilla JS) listing NBA 2K27 overall ratings and key attributes for 542 rostered NBA players.

- **Edition:** NBA 2K27, roster v222 (ratings as of Oct 2, 2026)
- **Source:** [2kAuction MyNBA – Current NBA roster](https://2kauction.com/mynba/players); top-end ratings cross-checked against the official 2K27 Top 100 and HoopsHype.
- Ratings change with roster moves and in-season updates.
- Free agents, G League, international and historic players are not included.
